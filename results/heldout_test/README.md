# Held-out Test Results

This folder contains the final held-out test evaluation outputs.

- `test_metrics.txt`: summary metrics
- `test_summary.json`: machine-readable summary
- `test_predictions.csv`: per-sample predictions
- `test_subgroups.csv`: sex/age subgroup analysis

The held-out test was evaluated only after model selection was completed and was not used for model or hyperparameter selection.
